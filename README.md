# Tier List App

A simple Android tier list app built with **Kotlin and Jetpack Compose**. Users can select images from their device and organize them into customizable tiers from S to F.

## Features

* Select multiple images from your device
* Drag and drop images between tiers
* S–F tier system
* Add and remove images from tiers
* Built with Jetpack Compose

## Tech Stack

* Kotlin
* Jetpack Compose
* Android Studio
* Coil — image loading
* Android Photo Picker

## Getting Started

1. Clone the repository.
2. Open the project in **Android Studio**.
3. Sync Gradle dependencies.
4. Run the app on an Android emulator or physical device.

## Project Goal

This project was created to practice Android development, Compose UI, state management, image handling, and drag-and-drop interactions.
